# 新能源不确定性优化调度：实际—预测配对公开数据集严格核验

**核验日期：** 2026-08-14（GMT+8）  
**纳入规则：** 数据必须能把风电或光伏的**实际/实现出力**与对同一交付时刻的**预测出力**按时间戳配对；原始分辨率为小时、15 分钟或 5 分钟；预测覆盖至少一个完整自然年；可从官方渠道公开取得并可用于学术研究。仅含实际值、仅含资源数据、或“潜力（HSL）”但没有预测值的数据均不纳入主清单。

> **核心结论。** 现有证据支持三类合格来源：**SMARD（德国联邦网络局）**、**ENTSO-E Transparency Platform** 与 **NREL/OEDI ARPA-E PERFORM**。其中，SMARD 和 ENTSO-E 是官方市场/透明度平台发布的实际或实现发电与预测；PERFORM 是 NREL 专为预测研究生成的“actuals + forecasts”基准，适合不确定性优化，但其 `actuals` 是模型化基准，而非电站电表计量。ERCOT 的原生公开报告中确有实际和预测产品，但本次未能核验一条可公开下载、至少覆盖完整一年的原生风光实际—预测历史配对文件，因此**不把 ERCOT 原生报告列为已合格数据集**。 [1] [2] [3]

## 二、重要方法边界

### 1. PERFORM 的“actuals”不是电表实测值

NREL 文档把数据命名为 `actuals`，但也明确说明：光伏序列由 NSRDB 资源和 SAM 仿真获得；风电资源由 WRF 生成，再形成风电 generation actuals。因此，PERFORM 是**同源、配对完备的合成/模型化实际—预测基准**，特别适合检验随机优化、分位数场景、机会约束和鲁棒调度；但如果论文主张“基于电站实测预测误差”，应优先选择 SMARD 或 ENTSO-E，并在方法中声明 PERFORM 的模型化性质。[2]

### 2. SMARD/ENTSO-E 的“实际”也需说明其统计口径

SMARD 手册说明其实现发电为向公共供电网馈入的净发电。部分技术和控制区可能混合使用测量、计划、预测或外推数据；光伏也可能含此类成分。ENTSO-E 的实际发电说明同样指出不同地区可能包含测量、计划与外推，且更新规则因区域不同。它们是官方发布的实际/实现发电统计序列，但不是对每座园区的未经处理 SCADA 电表读数。[3] [4]

### 3. 不确定性调度的配对规则

对于日前随机调度，建议以 `forecast_time`（PERFORM）或交付时段时间戳（SMARD/ENTSO-E）连接实际值；不能按“文件下载时间”连接。建议保持原始预测发布时间，并构造 `e_t=P_actual,t−P_forecast,t`。SMARD 的夏令时年应使用带 CET/CEST 偏移的时间戳转换到 UTC 后再合并；ENTSO-E API 响应已是 UTC，但年查询的日界仍以区域本地时区确定。

## 三、经核验后排除或暂不纳入的来源

| 来源 | 不纳入主清单的原因 |
|---|---|
| **EIA Form EIA-930 Hourly Generation by Energy Source** | 只提供实际的按燃料类型净发电；EIA 同一路径的预测字段是负荷日前预测，不是风光预测。因此不满足实际—预测配对硬条件。 |
| **ERCOT NP4-733-CD: Wind Power Production — Actual 5-Minute Averaged Values** | 官方说明为实际 `GEN` 与风电潜力 `HSL`，后者不是业务预测；不能当作实际—预测误差对。 |
| **ERCOT NP4-738-CD: Solar Power Production — Actual 5-Minute Averaged Values** | 官方页确认含实际 `GEN` 与太阳能潜力 `HSL`，且仅滚动历史 60 分钟；不含可核验的全年预测配对。 |
| **ERCOT NP4-732-CD: Wind Power Production** | 官方检索摘要显示可能包含实际 `GEN`、系统风电预测 `STWPF`、区域预测 `WGRPP`，但本次对其官方产品页的浏览访问被 ERCOT 安全服务拦截，且没有核验到可公开取得至少一年历史配对数据的归档路径、许可证、时区或文件结构。故列为**待 ERCOT 门户人工复核的候选**，不计入合格主清单。 |
| **ERCOT NP4-737-CD: Solar Power Production** | 官方摘要表明有实际太阳能小时生产及滚动历史/预测内容，但未核验到完整一年历史预测归档及字段/许可，故不计入合格主清单。 |

## 四、推荐的最小可复现实验方案

对于“新能源不确定性优化调度”论文，若目标是**预测误差建模、概率场景与算法对比**，优先选择 **PERFORM ERCOT 2018** 或 MISO/NYISO/SPP 2019：数据具备明确 `issue_time`、`forecast_time` 与 1–99 分位概率预测。若目标是**基于官方市场数据的实证调度**，选择 **SMARD Germany 2019 或 2023**：从下载中心分别导出 `Actual generation`、`Forecasted generation Day-Ahead`，地区取 Germany 或 DE/LU、粒度取 Quarterhour/Hour、格式取 CSV，再按 CET/CEST 规范转换和配对。若需要多国比较，选择 **ENTSO-E** 的实际发电 [16.1.B&C] 与风光日前预测 [14.1.D]，并使用响应中的 UTC 时间戳配对。
